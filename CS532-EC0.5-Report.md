## Question 3: In which direction does the 'pull' command work (does it send local changes to remote OR send remote changes to local)?
The Git pull command send remote changes to the local repository. It retrieves changes from GitHub and integrates them into the local repository on my computer.
The direction is: 
Remote Github repository -> local repository 

## Question 4: If you have committed a change on your local machine, but do not see the update on GitHub.com, what step might have you forgotten?
If changes have been committed locally, but do not appear on GitHub, the missing step is most likely git push.
The git commit command saves changes in the local repository, while git push uploads the commits to the remote GitHub repository.
